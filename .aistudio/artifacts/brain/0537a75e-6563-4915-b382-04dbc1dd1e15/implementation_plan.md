# خطة تنفيذ إعادة هيكلة الواجهة وإعدادات المكتب — الموثق الرقمي (v2 منقّحة)

**الهدف:** إعادة تصنيف الواجهة إلى ثلاث طبقات واضحة (ملف العقد · التحرير · إعدادات المكتب) بما يطابق برامج سطح المكتب الاحترافية، مع رفع سرعة التحرير وجودة الوصول والأداء، وبناء الأساس ليتحول البرنامج لاحقاً إلى تطبيق سطح مكتب دون إعادة كتابة.

---

## 0. القيود والمبادئ الحاكمة

1. **واجهة فقط:** لا يُعدَّل محرك التحرير ولا محرك تصدير/استيراد DOCX ولا طبقة التخزين. أي حاجة تُلبّى عبر محوّل (adapter) رفيع.
2. **قاعدة التصنيف (قاعدة القرار لأي زر):**
   - يخص الوثيقة المفتوحة الآن (جديد، فتح، تصدير، طباعة، سجل) ← **ملف العقد**.
   - يُستخدم أثناء الكتابة (تنسيق، بنية، بحث) ← **شريط التحرير**.
   - يُضبط مرة واحدة أو نادراً للمكتب كله ← **إعدادات المكتب**.
3. **إخفاء خلف مفتاح ميزة:** كل التغييرات خلف `ui.v2` حتى اكتمال الاختبار، فيمكن التراجع فوراً.
4. **لا فقد بيانات:** لا تُحذف الواجهة القديمة (نافذة الصيانة) إلا بعد إثبات تطابق وظيفي كامل.
5. **جاهزية سطح المكتب:** لا اعتماد على سلوك خاص بالمتصفح داخل مكونات الواجهة (انظر القسم 8).

## 2. سجل الأوامر (Command Registry) — الأساس

تُعرَّف كل وظيفة **مرة واحدة** في سجل مركزي، وتتغذى منه كل الواجهات: الأزرار، القوائم، الاختصارات، لوحة الأوامر، ولاحقاً قائمة النظام في سطح المكتب.

```ts
type Command = {
  id: string;                       // 'file.exportDocx'
  label: string;                    // نص عربي
  group: 'file' | 'edit' | 'structure' | 'office';
  icon?: string;
  shortcut?: string;                // 'Mod+B' (Mod = Ctrl أو ⌘)
  isEnabled?: (ctx: EditorContext) => boolean;
  isActive?: (ctx: EditorContext) => boolean;   // حالة الزر حسب التحديد
  run: (ctx: EditorContext) => void | Promise<void>;
};
```

- الاختصارات الأساسية: `Mod+B/I/U` · `Mod+F` · `Mod+P` (معاينة الطباعة) · `Mod+K` (لوحة الأوامر) · `Mod+,` (الإعدادات) · `Mod+Shift+E` (تصدير Word) · `Mod+Z / Mod+Shift+Z`.
- يظهر الاختصار في تلميح (tooltip) كل زر.
- لا اختصار يتعارض مع إدخال النص العربي أو لوحات المفاتيح غير اللاتينية؛ تُعالَج المفاتيح عبر `event.code` عند الحاجة.

## 3. الشريط العلوي (ملف العقد)

**الشكل المستهدف:**

- **قائمة «ملف»:** عقد جديد · فتح Word · السجل والمراجعات · إعدادات المكتب · (لاحقاً: آخر الملفات).
- **زر رئيسي بارز:** `تصدير Word`.
- **زر ثانوي:** `طباعة` (يفتح المعاينة، والطباعة منها؛ لا زر منفصل للمعاينة).
- **مؤشر الحفظ:** `جارٍ الحفظ…` ← `محفوظ ✓ 14:32` ← `تعذّر الحفظ` (قابل للنقر لإعادة المحاولة) ← `دون اتصال`.
- **أيقونة السجل:** تظهر الشارة العددية **فقط عند وجود عناصر** (لا `(0)`).
- **أيقونة الإعدادات (⚙) بنصّ «إعدادات المكتب»:** في نهاية الشريط.

**لا يوجد هنا:** تنسيق، وسوم، بنود، مساعد ذكي.
**لا يوجد زر «حفظ»:** الحفظ تلقائي؛ المؤشر يكفي.

## 4. شريط التحرير (Ribbon)

مجموعتان مفصولتان بفاصل بصري، وكل مجموعة لها تسمية صغيرة:

**تنسيق النص (بداية الشريط):**
تراجع/إعادة · نمط الفقرة (قائمة منسدلة: عادي، عنوان 1–3) · B I U · المحاذاة · قوائم نقطية/رقمية · جدول · ترويسة/تذييل · بحث واستبدال

**بنية العقد (نهاية الشريط):**
`#` بند جديد · `[ ]` وسم · تحويل التحديد إلى وسم ذكي

**سلوك إلزامي (جودة المحرر):**

1. **عدم سرقة التركيز:** الضغط على أي زر لا يُفقد المحرر التحديد ولا مؤشر الكتابة (`onMouseDown` + `preventDefault`، والإرجاع بالتركيز إلى المحرر بعد الأوامر).
2. **حالة الزر حسب التحديد:** `Bold` يظهر مفعّلاً إذا كان التحديد غامقاً (عبر `isActive`).
3. **الطيّ عند ضيق الشاشة:** ما لا يتسع ينتقل تلقائياً إلى قائمة «المزيد» بترتيب أولويات ثابت (بنية العقد لا تُطوى قبل التنسيق الثانوي).
4. **حجم الأهداف:** لا يقل هدف النقر عن 24×24 بكسل CSS (معيار WCAG 2.2 AA)، والمفضّل 32×32 على سطح المكتب.
5. **أيقونات بلا نص:** كل أيقونة لها `aria-label` وتلميح.

## 5. إعدادات المكتب

### 5.1 الشكل
عرض ملء الشاشة (overlay) بتنقل جانبي وحقل بحث في الإعدادات. يُفتح من: ملف ← إعدادات المكتب، أو `Mod+,`، أو لوحة الأوامر. يُغلق بـ `Esc`. له مسار قابل للربط (`#/settings/storage`) للاستخدام من أماكن أخرى (مثلاً: «تعذّر الحفظ ← افتح إعدادات التخزين»).

- **لا زر «حفظ» داخل الإعدادات:** تُطبَّق التغييرات فورياً وتُحفظ تلقائياً، مع «استعادة الافتراضي» لكل قسم.
- **تحميل كسول:** كل قسم مكوّن مستقل يُحمَّل عند فتحه (code splitting).

### 5.2 مخزن الإعدادات (Settings Store)

- مصدر وحيد للحقيقة، بمحددات (selectors) كي لا يُعاد رسم المحرر عند تغيير إعداد لا يخصه.
- مخطط مُتحقَّق منه (مثلاً Zod) وبحقل `schemaVersion`.
- **ترحيل:** عند أول تشغيل تُقرأ المفاتيح القديمة (تفضيلات المساعد، الترويسة، الخ) وتُحوَّل إلى المخطط الجديد؛ القيم المفقودة تُملأ بالافتراضيات؛ لا يُحذف القديم قبل نجاح الترحيل.
- يُقرأ ويُكتب عبر **طبقة التخزين المجردة** (القسم 8) لا مباشرة من `localStorage`/IndexedDB.

### 5.3 الأقسام

| القسم | المحتوى | ملاحظات تنفيذية |
|-------|---------|-----------------|
| **التخزين والنسخ** | ربط مجلد محلي · تصدير نسخة · استعادة نسخة · حالة الاتصال والحفظ · تذكير بالنسخ الاحتياطي | انظر 5.4 |
| **هوية المكتب** | اسم الموثق · العنوان · الهاتف · الشعار (اختياري) | تُستخدم تلقائياً في الترويسة؛ الشعار يُضغط ويُحدَّد حجمه |
| **نموذج الصفحة** | الهوامش (7/2/1/6 سم)، الخط (Arial 13)، التباعد (1.0)، الصفحة الأولى والأخيرة | يفسّر المسطرة وشريط الحالة؛ تنبيه عند تجاوز المساحة النصية الصافية |
| **القوالب** | عرض وإدارة القوالب · استيراد/تصدير · القالب الافتراضي للعقد الجديد | تبويب القوالب الجانبي يبقى «تطبيقاً على العقد الحالي» فقط |
| **البنود الجاهزة** | مكتبة البنود المقترحة · استيراد الحزمة القياسية | الشريط الجانبي «البنود» يبقى لهيكل العقد الحي |
| **المحرر** | المساعد الذكي (تفعيل منفصل لكل مشغّل: `/` `[` `#`) · ترويسة/تذييل افتراضياً · ترقيم الصفحات · الأرقام (عربية/هندية) | انظر القسم 6 |
| **حول / مساعدة** | الدليل · رقم الإصدار · اختصارات لوحة المفاتيح | قائمة الاختصارات تُولَّد من سجل الأوامر |
| *(مؤجَّل)* **الكتّاب والصلاحيات** | — | خلف مفتاح ميزة حتى توجد هوية مستخدم |

### 5.4 النسخ الاحتياطي (متطلبات السلامة)

- ملف النسخة JSON يحمل: `app`, `schemaVersion`, `exportedAt`, وبصمة `SHA-256` (عبر Web Crypto) للتحقق من السلامة.
- **الاستعادة:** تحقق من المخطط والبصمة ← **معاينة** (عدد العقود/القوالب/البنود) ← **لقطة تلقائية** للحالة الحالية قبل الكتابة ← تطبيق ذري (كله أو لا شيء) ← إمكانية التراجع.
- يجب أن تُستعاد النسخ القديمة (من «صيانة المكتب» الحالية) بنجاح عبر الترحيل.
- ربط المجلد المحلي عبر File System Access API **متاح في Chrome/Edge فقط**: يُكتشف الدعم ويُعرض بديل (تنزيل ملف) عند غيابه، دون رسالة خطأ.
- تذكير غير مزعج إن مرّت مدة طويلة دون نسخة احتياطية.

## 6. المساعد الذكي

- يُزال الزر الدائم من الشريطين.
- يبقى فعّالاً بالكتابة المباشرة (`/` `[` `#`)، وتفعيله منفصل لكل مشغّل في «المحرر».
- عند الإيقاف: يُكتب الحرف عادياً دون أي قوائم ودون تغيّر في التخطيط.
- **أثناء الإدخال بمحررات الإدخال (IME) أو التركيب** (`event.isComposing`) لا يُفعَّل المشغّل.
- `Esc` يغلق القائمة، وأسهم الاتجاه والإدخال للاختيار، وقارئ الشاشة يُعلَن بالنتائج (`role="listbox"`).
- مؤشر خفيف في شريط الحالة (اختياري) يوضح أن المساعد مفعّل، ولا زر.

## 7. معايير الجودة الحديثة

**الوصول (WCAG 2.2 AA):**
- شريط التحرير بنمط `role="toolbar"` مع تنقل بالأسهم (roving tabindex) وزر Tab واحد للدخول والخروج.
- نافذة الإعدادات: احتجاز التركيز، وإرجاعه إلى الزر الذي فتحها عند الإغلاق.
- تباين نص ≥ 4.5:1، وحلقة تركيز ظاهرة لا تُخفى بشريط ملتصق.
- لا تعتمد الحالة على اللون وحده (مثلاً «محفوظ» بنص وأيقونة).

**RTL والعربية:**
- خصائص CSS المنطقية فقط (`margin-inline-start`, `inset-inline-end`, …) ولا `left/right`.
- `dir="auto"` / `<bdi>` للأسماء والأرقام اللاتينية داخل النص العربي.
- خط عربي مضمَّن مع `font-display: swap` (يؤثر أيضاً على تطابق الطباعة).

**الأداء:**
- هدف INP < 200ms وLCP < 2.5s.
- مكونات الشريطين خفيفة ومحميّة من إعادة الرسم (`memo` + محددات)، فلا يتأثر المحرر بفتح الإعدادات.
- تحميل كسول لأقسام الإعدادات ومكتبة DOCX عند الطلب.
- لا عمل ثقيل في الخيط الرئيسي: تصدير/استيراد الملفات الكبيرة في Web Worker.

**الاستجابة والتجربة:**
- شاشات ضيقة: طيّ الشريط الثاني إلى «المزيد»، وطيّ الشريط الجانبي (مع تذكّر حالته).
- إشعار «تراجع» (toast) بدل نوافذ التأكيد للأفعال القابلة للعكس؛ نافذة تأكيد فقط للاستعادة والحذف النهائي.
- حالات فارغة وتحميل وخطأ معرَّفة لكل قسم.
- احترام `prefers-reduced-motion`.

**الخصوصية:** لا إرسال بيانات المكتب لأي جهة خارجية؛ تشفير محلي اختياري بكلمة مرور (Web Crypto) مؤجَّل لمرحلة لاحقة.

## 8. جاهزية سطح المكتب (Electron/Tauri لاحقاً)

- **طبقة تخزين مجردة** (`StorageService`): الواجهة لا تستدعي IndexedDB/`localStorage` مباشرة؛ على الويب تُنفَّذ بـ IndexedDB/OPFS، وعلى سطح المكتب بملفات/SQLite.
- **طبقة منصة** (`PlatformService`): فتح/حفظ ملف، طباعة، مجلد النسخ، آخر الملفات. على الويب تُنفَّذ بـ File System Access مع بديل التنزيل.
- **قوائم النظام** تُبنى لاحقاً من سجل الأوامر نفسه، دون إعادة تعريف.
- لا اعتماد على خادم للوظائف الأساسية (يعمل كاملاً دون إنترنت).

## 9. خطوات التنفيذ (بترتيب آمن وتغييرات صغيرة)

0. **خط أساس:** لقطات شاشة للواجهة الحالية + ملف DOCX مرجعي مُصدَّر + قائمة بسلوك «صيانة المكتب» الحالي. تُكتب اختبارات انحدار (regression) **قبل** أي تعديل.
1. **سجل الأوامر والاختصارات** (بلا تغيير مرئي): نقل الأفعال الحالية إلى السجل.
2. **مخزن الإعدادات + المخطط + الترحيل** (يقرأ المفاتيح القديمة).
3. **الشريط العلوي** (`EditorTopBar.tsx`): قائمة «ملف» + الأزرار الرئيسية + مؤشر الحفظ.
4. **شريط التحرير** (`EditorRibbon.tsx`): المجموعتان + الفاصل + سلوك التركيز + حالة الأزرار + الطيّ.
5. **هيكل الإعدادات** (مجلد `OfficeSettings/`): التنقل الجانبي، البحث، المسار، Esc، احتجاز التركيز. ثم الأقسام تدريجياً بهذا الترتيب: *التخزين والنسخ* (نقل «صيانة المكتب» بالكامل) ← *المحرر* ← *حول/مساعدة* ← *نموذج الصفحة* ← *هوية المكتب* ← *القوالب* ← *البنود الجاهزة*.
6. **الربط في `NotaryEditorApp.tsx`:** استبدال حالة نافذة الصيانة بحالة `settings: { open, section }`، وإزالة نافذة الصيانة القديمة بعد تحقق التطابق الوظيفي.
7. **لوحة الأوامر `Mod+K`:** بحث في الأوامر والإعدادات.
8. **صقل:** تدقيق الوصول، قياس الأداء، اختبار الشاشات الضيقة، ثم رفع مفتاح `ui.v2` تدريجياً.

## 10. الاختبار ومعايير القبول

**آلي (يُنفَّذ في كل تغيير):**
- `tsc --noEmit` + lint بلا أخطاء.
- اختبارات وحدة: مخطط الإعدادات والترحيل، سجل الأوامر، صحة النسخة الاحتياطية.
- اختبارات طرفية (Playwright): فتح الإعدادات، كل مشغّل للمساعد (مفعّل/موقوف)، التراجع، التصدير.
- فحص وصول آلي (axe-core) على الشريطين والإعدادات.
- مقارنة DOCX المُصدَّر بالمرجعي: الهوامش 7/2/1/6 والجداول والترويسة دون تغيير.

**يدوي (قائمة قبول):**
- [ ] كل وظيفة في الواجهة القديمة لها موضع في الجديدة (جدول تطابق موثّق).
- [ ] أي إعداد يُبلغ إليه خلال نقرتين أو عبر `Mod+K`.
- [ ] الضغط على أي زر تنسيق لا يُفقد التحديد.
- [ ] نسخة احتياطية قديمة تُستعاد بنجاح بعد الترحيل.
- [ ] استعادة فاشلة أو ملف تالف لا يُغيّر أي بيانات.
- [ ] المساعد الذكي: موقوف = لا قوائم؛ مفعّل = يعمل كالسابق.
- [ ] تنقل كامل بلوحة المفاتيح دون فخ تركيز، وإغلاق الإعدادات بـ `Esc` يعيد التركيز.
- [ ] عرض صحيح عند عرض 1024 بكسل وعرض 768 بكسل.
- [ ] تجربة عقد قياسي كامل مع 2–3 موثقين فعليين وتسجيل زمن الإنجاز مقارنة بالحالي.

## 11. نقاط تحتاج قراراً

1. ما المقصود بـ«رسائل الختم الرسمية» في هوية المكتب (نص ثابت؟ صورة ختم؟ بيانات توقيع؟)
2. هل يوجد (أو سيوجد) تسجيل دخول متعدد المستخدمين؟ يحدد توقيت قسم «الكتّاب والصلاحيات».
3. ما المتصفحات/الأنظمة المستهدفة قبل الانتقال لسطح المكتب؟ (يحدد أهمية بديل File System Access).
4. توحيد المصطلح: «وسم» أم «متغير»؟ تستخدم الواجهة الحالية الاثنين (الوسوم، متغيرات العقد). يُنصح بمصطلح واحد.

---

## 12. خارج النطاق حالياً

- تعدد التبويبات (عقود متعددة)، المزامنة بين الأجهزة، التشفير المحلي، قائمة آخر الملفات: تُبنى لاحقاً على الأساس نفسه (سجل الأوامر + طبقات التخزين والمنصة).
