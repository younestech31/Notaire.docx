# محرر العقود التوثيقية الذكي (الموثق الرقمي) — الخطة الهندسية الرسمية (الإصدار 2.4)

منصة مكتبية احترافية تجمع بين **دقة ومظهر Microsoft Word الحقيقي** (ورقة A4 قياسية، مسطرة أفقية وعمودية، هوامش توثيقية مرئية، ومحرك OpenXML ثنائي الاتجاه) وبين **السرعة الإنتاجية الفائقة لتطبيق `localnotaire`** (نظام البنود الجاهزة، تمييز الوسوم الذكية، استمارة المتغيرات مع عداد النواقص، **مولد الوثائق المشتقة القابلة للتعديل الكامل**، الحفظ التلقائي، **نظام مقارنة النسخ Diff**، و**أرشيف التحميلات**).

### القرارات الهندسية المعتمدة والثابتة

> [!IMPORTANT]
> تلتزم هذه الخطة بالقواعد التوثيقية الصارمة لمكتبكم، وتعمل بالكامل دون اتصال بالإنترنت ودون أي خدمات مدفوعة:

| القاعدة الهندسية | القيمة الثابتة المعتمدة |
| :--- | :--- |
| **الخط والحجم** | `Arial 13pt` دائماً وأبداً (`w:sz="26"` و `w:szCs="26"`) |
| **الهوامش التوثيقية** | يمين `7 سم` (`3969 twips`) · يسار `2 سم` (`1134 twips`) · أعلى `1 سم` (`567 twips`) · أسفل `6 سم` (`3402 twips`) |
| **تباعد الأسطر والفقرات** | تباعد أسطر مفرد `1.0` (`w:line="240"`) + صفر مسافات قبل/بعد الفقرات (`w:before="0" w:after="0"`) |
| **نواة التحرير** | محرر DOM مخصص بصفحة A4 حقيقية (`12 سم` عرض صافي) + محرك OpenXML يعمل 100% دون اتصال |

### 1. المزايا الاستراتيجية المعتمدة في الإصدار 2.4

#### أ. ترتيب الشريط الجانبي (حسب كثافة الاستخدام اليومي)
1. **البنود الجاهزة** (التبويب الافتراضي الأول)
2. **الأطراف والتعيينات** (مع جدول الوصف التقسيمي لاختيار رقم الحصة)
3. **قوالب المكتب + قوالب الوثائق المشتقة**
4. **المستندات المحفوظة + سجل النسخ + أرشيف التحميلات**

#### ب. نظام المتغيرات الذكية + عداد النواقص (المصدر الموحد للبيانات)
- **صيغة الوسوم**: `{{اسم_المتغير}}`
- **التمييز البصري داخل المحرر**: لون وردي/أرجواني غامق (`#9d174d` / `#c2185b`) بخط عريض وخلفية وردية خفيفة (`#fdf2f8`) داخل `<span class="smart-tag" contenteditable="false" data-var="...">`.
- **النقر المزدوج (`Double-Click`)**: نقر مزدوج على أي وسم داخل ورقة الـ A4 يفتح نافذة تعبئة فورية لهذا المتغير أو ينقل التركيز إليه في استمارة المتغيرات.
- **زر «استمارة المتغيرات»**: يعرض عداداً بلون **أحمر/برتقالي** لعدد المتغيرات غير المعبأة (مثال: `استمارة المتغيرات · 3 غير معبأة !`)، ويتحول إلى **الأخضر** عند اكتمال تعبئة كافة المتغيرات.

#### ج. مولد الوثائق المشتقة (`Derived Documents Generator`) — بضوابط صريحة
بمجرد اكتمال العقد الرئيسي وتعبئة المتغيرات، يستطيع الكاتب بضغطة واحدة من قائمة **«توليد الوثائق المشتقة»** في شريط الأدوات توليد وتصدير الوثائق التوثيقية المرافقة:

| نوع الوثيقة المشتقة | الرمز البرمجي | الوظيفة في النظام |
| :--- | :--- | :--- |
| **الأصل WORD** | `acte` | تصدير العقد التوثيقي الأصلي الكامل |
| **المستخرج** | `extrait` | توليد مستخرج العقد الموجه لمفتشية التسجيل والطابع |
| **إجراء الشهر العقاري** | `publication` | توليد وثيقة إجراء الشهر العقاري الموجهة للمحافظة العقارية |
| **شهادة البيع / المعاملة** | `attestation` | توليد شهادة توثيقية تسلم للأطراف إثباتاً لإبرام العقد |
| **الصيغة التنفيذية (النسخة)** | `proce_verbal` | توليد النسخة التنفيذية الممهورة بصيغة التنفيذ الرسمية |
| **مستخرج الهبات** | `extrait_donation` | توليد مستخرج خاص بعقود الهبة والتبرعات |
| **طلب PR4BIS** | `br4bis` | توليد طلب معلومات عقارية / شهادة سلبية من بيانات الأطراف والعقار |
| **وصل استلام الوديعة** | `recu_depot` | توليد وصل إيداع المبالغ أو الوثائق بالمكتب |

- **الضوابط الهندسية الصريحة لمولد الوثائق المشتقة**:
  1. **قوالب الوثائق المشتقة مرئية وقابلة للتعديل الكامل من داخل التطبيق**:
     - قوالب المشتقات **ليست ملفات ثابتة أو مخفية في الكود البرمجي**، بل تُعامل تماماً مثل قوالب المكتب والبنود؛ حيث يمكن للكاتب فتح أي قالب وثيقة مشتقة (كالمستخرج أو إجراء الشهر أو شهادة البيع) داخل محرر الـ A4، وتعديل صياغته وجداوله ووسومه بحرية تامة، أو استيراد ملف `.docx` خاص بالمكتب ليحل محله، أو إضافة قوالب مشتقة جديدة كلياً وحفظها في `IndexedDB`.
  2. **الاعتماد الحصري على «استمارة المتغيرات + بيانات الأطراف والتعيينات» (`Single Source of Truth`)**:
     - يعتمد توليد أي وثيقة مشتقة **حصرياً ومباشرةً** على القيم الموجودة حالياً في **«استمارة المتغيرات» + بيانات الأطراف والتعيينات (وجدول الوصف التقسيمي)** الخاصة بالعقد المفتوح.
     - إذا طلب الكاتب توليد وثيقة مشتقة يحتوي قالبها على وسوم `{{...}}` لم تُعبأ بعد في استمارة المتغيرات، يعرض النظام تنبيهاً واضحاً بالمتغيرات الناقصة مع إمكانية تعبئتها فوراً قبل التصدير.
  3. **التصدير الفوري والحفظ في أرشيف التحميلات**:
     - يُصدّر الملف المشتق بصيغة `.docx` بنفس القواعد الصارمة (`Arial 13pt` + هوامش `7/2/1/6 سم` + تباعد `1.0`)، ويُحفظ تلقائياً في **أرشيف التحميلات** مع التاريخ ونوع الوثيقة المشتقة.

#### د. نظام البنود الجاهزة (`Clause System`)
- كل بند يمثل فقرة أو عدة فقرات/جداول محفوظة قابلة للتفعيل/التعطيل (`Checkbox`) وإعادة الترتيب بالسحب والإفلات أو الأسهم.
- يظهر البند المُدرج داخل ورقة الـ A4 في حاوية مرئية خفيفة أثناء التحرير فقط (`clause-container` بإطار منقط هادئ وشارة جانبية تحمل اسم البند)، وتختفي هذه العلامات تماماً عند التصدير إلى Word والطباعة.

#### هـ. الحفظ التلقائي + سجل النسخ + نظام مقارنة النسخ (`Version Diff`)
- حفظ تلقائي بعد `1800ms` من التوقف عن الكتابة في `IndexedDB`.
- كل عملية حفظ تُسجَّل في جدول **«سجل التعديلات والنسخ»** مع التاريخ والساعة واسم الكاتب/الجهاز وزر **«مقارنة»**.
- عند الضغط على **«مقارنة النسخ»** تُفتح نافذة تعرض الفرق بين النسختين (**النص المضاف بالأخضر**، **والمحذوف بالأحمر ومشطوب**).

#### و. أرشيف التحميلات (`Download Archive`) ومصادر بدء التحرير المتعددة
- جدول مستقل يعرض كل الملفات التي تم تصديرها سابقاً من العقد (الأصل `DOCX` + جميع الوثائق المشتقة المولّدة مثل المستخرج، إجراء الشهر، شهادة البيع، الصيغة التنفيذية...) مع التاريخ ونوع الوثيقة وأزرار **«فتح في المحرر»** و **«إعادة تحميل (.docx)»**.
- عند إنشاء عقد جديد تتوفر 4 مصادر محلية: قوالب المكتب، المسودات السابقة، استيراد `.docx` من الجهاز، أو استيراد من أرشيف التحميلات.

### 3. ترتيب الأولويات المعتمد وحدود النواة (MVP Scope & Boundaries)

- **P0 — النواة الحرجة**:
  1. محرر DOM مخصص (ورقة A4 + مسطرة أفقية وعمودية + القواعد الثلاث الثابتة: `Arial 13pt`، هوامش `7/2/1/6 سم`، تباعد `1.0` بدون مسافات فقرات).
  2. محرك OpenXML استيراد/تصدير كامل يعمل دون اتصال.
  3. نظام الوسوم الذكية `{{...}}` باللون الوردي الغامق (`#9d174d`) + النقر المزدوج للتحرير السريع + **«استمارة المتغيرات»** مع عداد النواقص الأحمر/البرتقالي.
  4. الشريط الجانبي بالترتيب المعتمد (`البنود الجاهزة` أولاً) + الحفظ التلقائي في `IndexedDB`.
- **P1 — القوة الإنتاجية (أولوية قصوى بعد النواة مباشرة)**:
  1. **مولد الوثائق المشتقة (`Derived Documents Generator`)**: المستخرج، إجراء الشهر، شهادة البيع، الصيغة التنفيذية، مستخرج الهبات، طلب PR4BIS، وصل استلام الوديعة، مع **قابلية تحرير قوالبها من داخل المحرر** واعتمادها الحصري على بيانات استمارة المتغيرات والأطراف والتعيينات.
  2. نظام البنود الجاهزة التفاعلي (تفعيل/تعطيل + ترتيب + حاوية مرئية خفيفة تختفي عند التصدير).
  3. **نظام مقارنة النسخ (`Diff Viewer`)** بالأخضر والأحمر + **أرشيف التحميلات (`Download Archive`)** + **مصادر بدء التحرير المتعددة**.
  4. الجداول المتقدمة + القوائم الأبجدية العربية + التراجع/الإعادة + البحث والاستبدال + الترويسة والتذييل وترقيم الصفحات.
- **خارج نطاق النواة الحالية (موديولات إدارية محيطية مؤجلة لمراحل لاحقة)**:
  - *الوضعية الجبائية التفصيلية*، *إدارة الصكوك والودائع والخزينة (المحاسبة)*، و*بطاقة الاستقبال والإيداع الإدارية* تُعد وظائف محيطية بالمكتب وليست من نواة محرر العقود، وتُترك كموديولات مستقلة لاحقاً للحفاظ على سرعة وتركيز نواة التحرير والتوليد التوثيقي.
