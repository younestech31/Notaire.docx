# الموثق الرقمي (Notaire.docx) — محرر العقود التوثيقية الجزائري

نظام مكتبي رقمي مخصص لمكاتب التوثيق الجزائرية لتحرير العقود التوثيقية فوق ورقة **A4 حقيقية** بالمقاييس القانونية الرسمية (المرسوم التنفيذي 08-244)، مع محرك فهرسة وختم رقمي (`SHA-256`)، ومتابعة دفعات التسجيل والشهر العقاري، ومحرك بنود حية واستمارة متغيرات ديناميكية، واستيراد وتصدير مباشر لملفات **Microsoft Word (`.docx`)**.

---

## المزايا الأساسية والمعمارية

### 1. ورقة العقد الرسمية (A4) والترقيم التوثيقي الجزائري (`../..`)
- **الهوامش التوثيقية الثابتة**: يمين `7 سم`، يسار `2 سم`، أعلى `1 سم`، أسفل `6 سم` (صافي عمود المتن: عرض `12 سم` × ارتفاع `22.7 سم`).
- **الخط الرسمي الثابت**: `Arial` بحجم `13pt` وتباعد أسطر `1.0` ومحاذاة مضبوطة (`Justify`) من اليمين إلى اليسار (`RTL`).
- **محرك الترقيم التوثيقي الحقيقي (`lib/notarial-pagination.ts`)**:
  - يقيس ارتفاع الكتل فعلياً داخل حاوية DOM مطابقة لعمود `12 سم × 22.7 سم`.
  - يدرج إشارة التتابع `../..` كسطر مستقل (`<p align="left" dir="rtl">`) تحت آخر سطر فعلي في كل صفحة غير أخيرة، ويضع في الصفحة الختامية عبارة: **«الصفحة {العدد بالحروف} والأخيرة»** (مثل: *الصفحة التاسعة والأخيرة*) دون استخدام الترقيم الرقمي `1/9` أو التذييل.
  - **شطر الفقرات الطويلة مع حفظ التنسيق الداخلي**: عند امتداد فقرة واحدة عبر حدود الصفحة، يتم تقسيمها مع الإبقاء الكامل على التنسيقات الداخلية (`<strong>`، `<u>`، والوسوم الذكية `[متغير]`) دون بتر أو مسح للتنسيق.
  - **معاينة مطابقة للطباعة**: زر مباشر أسفل الورقة وفي الشريط العلوي لمعاينة مواضع `../..` وفواصل الصفحات كما ستُطبع وتُصدَّر إلى `.docx`.

### 2. المركز التوثيقي (`NotaryHubPanel`) — الفهرسة والختم والتسجيل والشهر
- **الفهرسة الرسمية والختم الرقمي (`lib/indexing-engine.ts`)**:
  - اقتراح تلقائي لرقم الفهرس السنوي التتابعي (`آخر فهرس + 1`) للسنة الجارية مع منع تكرار أي رقم فهرس في نفس السنة، ورفض فهرسة أي عقد فارغ المتن.
  - حفظ المتن الحي من المحرر مباشرةً قبل التوليد، ثم حقن `[رقم_الفهرس]` و`[رقم_الإيداع]` و`[تاريخ_العقد]`، وتوليد ملف `.docx` الرسمي وختمه ببصمة `SHA-256` غير قابلة للتعديل (`sealContractOriginal`).
  - تحويل حالة العقد إلى `signed_indexed` وتسجيل مراجعة رسمية في سجل المراجعات.
- **قفل الأصل المعتمد بعد الفهرسة**:
  - بمجرد فهرسة العقد وختمه، يُقفل متن الورقة (`isBodyLocked`) وتُعطَّل أوامر تعديل النص في شريط الأدوات لمنع أي تحريف غير مقصود بعد التوقيع، مع بقاء إمكانية تحديث مراجع التسجيل والشهر العقاري أو فتح القفل بتأكيد صريح من الموثق.
- **دفعات التسجيل (`RegistrationBatch`) ومسار الشهر العقاري (`PublicationTrack`)**:
  - ربط العقود بدفعات مفتشية التسجيل والطابع وبإيداعات المحافظة العقارية.
  - مزامنة عكسية تلقائية لحالة العقد (`deposited_for_registration`، `registered`، `deposited_for_publication`، `published`) وحقن `[مراجع_التسجيل]` و`[مراجع_الشهر]` في متغيرات العقد والوثائق المشتقة.
  - **معالجة حالات الرفض والتسوية**: دعم حالتي `registration_rejected` (مرفوض للتسجيل/التسوية) و`publication_rejected` (رفض/تحفظ بالشهر العقاري) مع تدوين سبب الرفض في مراجع العقد وسجل المراجعات دون إبقاء العقد معلقاً كـ«مودع».

### 3. إدارة البنود الحية والشروط المخصصة (`components/ClausesPanel.tsx`)
- استخراج البنود الحية مباشرة من عناوين `#` وحاويات البنود داخل ورقة العقد.
- تفعيل/تعطيل أي بند (`Checkbox`)، قفل البند لحمايته، السحب والإفلات لإعادة الترتيب، وربط البنود بشروط المكتب المخصصة.

### 4. الاستمارة الديناميكية المقسمة حسب البنود (`components/SmartModals.tsx`)
- تجميع المتغيرات تلقائياً تحت عنوان كل بند يحتويها مع عرض السياق النصي للبند.
- التفقيط التلقائي للمبالغ المالية والتواريخ باللسان العربي القانوني (`lib/tafqeet.ts`).
- دعم تعدد الأطراف (`ContractPartyCard`) ودليل الأطراف والعقارات المحفوظة وجداول الوصف التقسيمي.

### 5. التخزين الهجين وجسر سطح المكتب (`IndexedDB` + `DesktopOfficeBridge`)
- **في المتصفح (`lib/storage-browser.ts`)**: تخزين أساسي في `IndexedDB` (الإصدار 7) يشمل العقود، المجلدات، الأصول المختومة `sealed_originals`، دفعات التسجيل، ومسارات الشهر، مع `localStorage` كطبقة احتياطية عند تعذر `IndexedDB` فقط.
- **جسر سطح المكتب (`lib/desktop-bridge.ts` & `lib/storage-desktop.ts`)**: يدعم الربط مع غلاف سطح المكتب (`window.__NOTAIRE_DESKTOP__` لـ Tauri/Electron) أو ربط مجلد محلي مباشر على القرص عبر `File System Access API` (`mountLocalOfficeDirectory`) لحفظ قواعد البيانات والأصول المختومة `.docx` مباشرةً على جهاز المكتب.

## هيكل الملفات الرئيسي

```text
├── app/
│   ├── layout.tsx                       # التخطيط الجذري والخطوط والاتجاه RTL
│   ├── page.tsx                         # الصفحة الرئيسية للمحرر
│   └── globals.css                      # أنماط ورقة A4 التوثيقية والطباعة (@page A4)
├── components/
│   ├── NotaryEditorApp.tsx              # نواة المحرر وتنسيق الحالة والأوامر
│   ├── EditorTopBar.tsx                 # الشريط العلوي (العنوان + مجموعة ملف والنسخ الاحتياطي)
│   ├── EditorRibbon.tsx                 # شريط الأدوات التوثيقي مع احترام قفل الأصل المعتمد
│   ├── ClausesPanel.tsx                 # لوحة إدارة بنود العقد الحية والشروط المخصصة
│   ├── NotaryHubPanel.tsx               # المركز التوثيقي (الفهرسة، الختم، دفعات التسجيل، الشهر، والرفض)
│   ├── FolderTreeExplorer.tsx           # مستكشف شجرة مجلدات وعقود المكتب وحالاتها
│   ├── SidebarWorkspace.tsx             # الشريط الجانبي الموحد للأقسام الخمسة
│   ├── RevisionsDiffModal.tsx           # سجل المراجعات والمقارنة جنباً إلى جنب
│   ├── SmartModals.tsx                  # نوافذ استمارة المتغيرات ومعاينة الاستيراد والقوالب
│   ├── InlineVariablePopover.tsx        # الفقاعة العائمة لتعبئة الوسم بنقرة واحدة
│   ├── editor/
│   │   ├── EditorA4Canvas.tsx           # ورقة A4 التوثيقية ومعاينة الترقيم والطباعة
│   │   ├── EditorStatusBars.tsx         # أشرطة الحالة والختم والبحث والاستبدال العربي
│   │   └── EditorModalsHost.tsx         # مضيف النوافذ المنبثقة والشريط الجانبي المطوي
│   ├── modals/                          # نوافذ القوالب والبدء المتعدد وجولة التعريف
│   └── sidebar/                         # تبويبات الأطراف والعقارات والأرشيف
├── lib/
│   ├── types.ts                         # تعريفات الأنواع ودورة حياة العقد والأصول المعتمدة
│   ├── notarial-pagination.ts           # محرك الترقيم التوثيقي (../..) بقياس DOM 12سم×22.7سم وحفظ التنسيق
│   ├── indexing-engine.ts               # محرك الفهرسة السنوية، الختم الرقمي، ومزامنة التسجيل والشهر والرفض
│   ├── document-io-workflows.ts         # مسارات تصدير وختم Word، المشتقات، والنسخ الاحتياطي
│   ├── clause-outline-engine.ts         # محرك هيكلة البنود الحية وبطاقات الأطراف
│   ├── docx-importer.ts                 # مستورد ملفات Word (.docx) وتحويلها لفقرات وبنود
│   ├── docx-engine.ts                   # محرك بناء وتصدير ملفات Word (.docx) بالمقاييس الرسمية
│   ├── editor-utils.ts                  # دوال معالجة الـ DOM والوسوم والبحث العربي
│   ├── office-store.ts                  # عقد التخزين الموحد (OfficeStore) وبصمة SHA-256
│   ├── desktop-bridge.ts                # جسر سطح المكتب ومزامنة المجلد المحلي على القرص
│   ├── storage-browser.ts               # محرك تخزين IndexedDB (DB v7)
│   ├── storage-desktop.ts               # محرك تخزين سطح المكتب
│   ├── storage.ts                       # بوابة التخزين الموحدة
│   ├── tafqeet.ts                       # محرك تفقيط المبالغ المالية والتواريخ القانونية
│   └── table-grid.ts                    # إدارة الجداول التوثيقية (إدراج، دمج، تقسيم الخلايا)
└── tests/
    ├── ts-loader.mjs                    # محمل وحدات TypeScript لبيئة الاختبار
    └── notarial-core.test.ts            # اختبارات الوحدة الآلية (الترقيم، شطر الفقرات المنسقة، الفهرسة، والرفض)
```

## التشغيل المحلي والاختبارات والبناء

```bash

# تشغيل خادم التطوير (المنفذ 3000)
npm run dev

npm run build
```
