# الموثق الرقمي (Notaire.docx) — محرر العقود التوثيقية الجزائري

نظام مكتبي رقمي مخصص لمكاتب التوثيق الجزائرية لتحرير العقود التوثيقية فوق ورقة **A4 حقيقية** بالمقاييس القانونية الرسمية، مع محرك قوالب وبنود حية واستمارة متغيرات ديناميكية واستيراد وتصدير مباشر لملفات **Microsoft Word (`.docx`)**.

---

## المزايا الأساسية والمعمارية

### 1. ورقة العقد الرسمية (A4) والطباعة المطابقة
- **الهوامش التوثيقية الثابتة**: يمين `7 سم`، يسار `2 سم`، أعلى `1 سم`، أسفل `6 سم` (صافي المساحة النصية `12 سم`).
- **الخط الرسمي الثابت**: `Arial` بحجم `13pt` وتباعد أسطر `1.0` ومحاذاة مضبوطة (`Justify`) من اليمين إلى اليسار (`RTL`).
- **تصدير واستيراد Word (`.docx`)**: توافق ثنائي الاتجاه مع ملفات وورد مع الحفاظ على الجداول والتنسيقات والوسوم الذكية `[اسم_المتغير]`.

### 2. الشريط العلوي المقسّم إلى 3 مجموعات ثابتة
1. **مجموعة «ملف» والنسخ الاحتياطي للمكتب (`components/EditorTopBar.tsx`)**:
   - عقد جديد، فتح ملف Word، معاينة الدمج الحي جنباً إلى جنب، سجل المراجعات، الطباعة، وتصدير Word.
   - **النسخ الاحتياطي الفوري للمكتب**: زر **«تصدير نسخة المكتب»** وزر **«استعادة»** (حزمة `BackupBundle` شاملة بصيغة JSON) مع **مؤشر تاريخ آخر نسخ احتياطي** لحماية قاعدة بيانات المكتب المحلية والأصول المعتمدة.
2. **مجموعة «تنسيق» (`components/EditorRibbon.tsx`)**:
   - تراجع/إعادة، غامق/مائل/تسطير، المحاذاة الأربع، القوائم الرقمية والأبجدية، الجداول التوثيقية، الترويسة والترقيم، وقائمة **«المزيد»** للأدوات الثانوية (فاصل صفحات، ألوان، مسافة بادئة، اتجاه النص، تكبير/تصغير، بحث واستبدال عربي).
3. **مجموعة «توثيق» (`components/EditorRibbon.tsx`)**:
   - زر **«استمارة المتغيرات»** أولاً وبشكل بارز مع عداد الحقول غير المعبأة.
   - **تحويل المحدد لوسم `[ ]`** بضغطة واحدة، **إدراج وسم**، و**`# بند جديد`**.
   - قائمة **«المشتقات والمقارنة»** لتوليد الوثائق المشتقة (الفهرس، خلاصة العقد، جدول التسجيل، استمارة الشهر العقاري، شهادة التوثيق) ومقارنة المراجعات.

### 3. إدارة البنود الحية والشروط المخصصة (`components/ClausesPanel.tsx`)
- **المصدر الوحيد للحقيقة**: استخراج البنود الحية مباشرة من عناوين `#` وحاويات البنود داخل ورقة العقد.
- **التحكم الفوري**: تفعيل/تعطيل أي بند (`Checkbox`) لإخفائه أو إظهاره في العقد والتصدير مع الاحتفاظ بموضعه الدقيق، قفل البند لحمايته، السحب والإفلات لإعادة الترتيب، وتحرير عنوان البند بالنقر المزدوج.
- **شروط المكتب المخصصة للبنود**: تبدأ القائمة فارغة ليحدد المكتب شروطه الخاصة (منطقية `نعم/لا` أو نصية) ويربط أي بند بشرط ليظهر أو يختفي تلقائياً عند تغيير حالة الشرط.
- **اختصارات سريعة في ذيل قائمة البنود**: زر **«حفظ كقالب مكتب»** وزر **«إفراغ البنود المفعلة»**.

### 4. الاستمارة الديناميكية المقسمة حسب البنود (`components/SmartModals.tsx` & `components/SidebarWorkspace.tsx`)
- تجميع المتغيرات تلقائياً تحت **عنوان كل بند** يحتويها بترتيب ورودها في العقد.
- عرض **النص المرجعي الكامل للبند** بجانب حقول المتغيرات مع تظليل الوسوم ليعرف المحرر السياق القانوني الدقيق أثناء التعبئة.
- قائمة منسدلة لكل متغير لتحديد نوعه (**نص / رقم / تاريخ**) مع التفقيط التلقائي للمبالغ والتواريخ باللسان العربي القانوني.
- دعم تعدد الأطراف (`بائع 1، بائع 2، مشتري 1...`) وتقسيم الحقول إلى مجموعات: **الأطراف، العقار، الثمن، الوضعية الجبائية، والفهرس**.

### 5. سجل التعديلات والمقارنة (`components/RevisionsDiffModal.tsx`)
- جدول مراجعات مفصل يعرض: **التاريخ والوقت | المحرر/الكاتب | تفاصيل التعديل | إجراءات المقارنة والاستعادة**.
- نافذة مقارنة جنباً إلى جنب مع تظليل الإضافات والحذوفات كلمة بكلمة.

## هيكل الملفات الرئيسي

```text
├── app/
│   ├── layout.tsx                 # التخطيط الجذري والخطوط والاتجاه RTL
│   ├── page.tsx                   # الصفحة الرئيسية للمحرر
│   └── globals.css                # أنماط ورقة A4 التوثيقية والطباعة
├── components/
│   ├── NotaryEditorApp.tsx        # نواة المحرر وحالة العقد وربط المكونات
│   ├── EditorTopBar.tsx           # الشريط العلوي (العنوان + مجموعة ملف والنسخ الاحتياطي للمكتب)
│   ├── EditorRibbon.tsx           # شريط الأدوات التوثيقي (مجموعتا تنسيق وتوثيق)
│   ├── ClausesPanel.tsx           # لوحة إدارة بنود العقد الحية والشروط المخصصة ومكتبة البنود
│   ├── SidebarWorkspace.tsx       # الشريط الجانبي (الأطراف والتعيينات، القوالب، والأرشيف)
│   ├── RevisionsDiffModal.tsx     # جدول سجل المراجعات المفصل ونافذة المقارنة جنباً إلى جنب
│   ├── SmartModals.tsx            # نافذة استمارة المتغيرات المقسمة حسب البنود ونوافذ القوالب
│   └── InlineVariablePopover.tsx  # الفقاعة العائمة لتعبئة الوسم بنقرة واحدة داخل الورقة
└── lib/
    ├── types.ts                   # تعريفات الأنواع والبيانات التوثيقية والأصول المعتمدة
    ├── office-store.ts            # منفذ التخزين الموحد (OfficeStore) وبصمة SHA-256
    ├── desktop-bridge.ts          # جسر سطح المكتب المحلي (DesktopOfficeBridge)
    ├── storage-browser.ts         # محرك تخزين المتصفح المحلي
    ├── storage-desktop.ts         # محرك تخزين سطح المكتب عبر الجسر
    ├── storage.ts                 # نقطة الدخول الموحدة للتخزين والنسخ الاحتياطي
    ├── editor-utils.ts            # دوال معالجة الـ DOM والبنود الحية والوسوم والبحث العربي
    ├── docx-engine.ts             # محرك استيراد وتصدير ملفات Word (.docx) بالمقاييس الرسمية
    ├── tafqeet.ts                 # محرك تفقيط المبالغ المالية والتواريخ القانونية
    └── table-grid.ts              # إدارة الجداول التوثيقية (إدراج، دمج، تقسيم الخلايا)
```
